# Clinch Supply, landing page

Site estático da Clinch Supply: sapatilhas e luvas de boxe em 3D giráveis (Three.js) com animações (GSAP).

- `index.html`: o site publicado (gerado, não edite à mão)
- `src/page.html`: estrutura e estilos
- `src/ui.js`: dados dos produtos, preços e interações da página
- `src/clinch3d.js`: modelos 3D das sapatilhas e da luva
- `src/app3d.js`: liga os modelos 3D à página

Para alterar: edite os arquivos em `src/` e rode `python3 build.py` para gerar o `index.html`.

Publicado pelo GitHub Pages (branch `main`, pasta raiz).
